# Focussoft HQ

We build peer-to-peer marketplaces. [RCFeed](https://rcfeed.com) is our marketplace for radio-controlled hobby gear. [MarketSDK](https://marketsdk.com) is a headless API that puts a marketplace inside your SaaS product: sellers, listings, search, orders, payments on your own Stripe account, reputation, disputes, and moderation.

This organization holds our public code: the MarketSDK client libraries and the generator that produces them.

| Library | Install |
| --- | --- |
| [TypeScript](https://github.com/focussofthq/marketsdk-typescript) | `npm install @marketsdk/js` |
| [Python](https://github.com/focussofthq/marketsdk-python) | `pip install marketsdk` |
| [Go](https://github.com/focussofthq/marketsdk-go) | `go get github.com/focussofthq/marketsdk-go` |
| [Java](https://github.com/focussofthq/marketsdk-java) | `com.marketsdk:marketsdk-java` on Maven Central |
| [C#](https://github.com/focussofthq/marketsdk-csharp) | `dotnet add package MarketSDK` |
| [PHP](https://github.com/focussofthq/marketsdk-php) | `composer require marketsdk/php` |

Every library is generated from the MarketSDK API description by [marketsdk-sdk-generator](https://github.com/focussofthq/marketsdk-sdk-generator), so none is ever behind the API. All of it is MIT licensed. The guide is at [marketsdk.com/docs/sdks](https://marketsdk.com/docs/sdks).

Found a problem in a library? Open an issue on its repository. Anything else: [hello@focussofthq.com](mailto:hello@focussofthq.com).
